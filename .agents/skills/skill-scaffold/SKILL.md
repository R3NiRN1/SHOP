# Scaffold Maintenance Skill

## When to use
Use this skill when updating the repository's agent control plane scaffold, including guardrails, workflows, templates, and documentation.

## Workflow
1. Confirm the requested scope and avoid unrelated working tree changes.
2. Update scaffold files under `AGENTS.md`, `.agents/`, `.github/`, `docs/`, and `tools/`.
3. Run targeted checks for modified files.
4. Summarize the change set and verification performed.
