# Agent Control Plane

This scaffold establishes a lightweight agent control plane for the SHOP repository.

## Included pieces
- `AGENTS.md` for repository guardrails.
- `.agents/skills/` for reusable agent workflows.
- `.github/pull_request_template.md` for required PR structure.
- `.github/workflows/agent-contract.yml` for PR contract enforcement.
- `tools/bootstrap-agent-control-plane.sh` for local setup help.

## Intended use
Use these files as a starting point and refine them as the repository's automation needs become more specific.
