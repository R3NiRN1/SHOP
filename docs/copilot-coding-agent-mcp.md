# Copilot coding agent MCP setup

1. Go to: Repo Settings → Copilot → Coding agent → MCP configuration
2. Paste the JSON from `docs/mcp/github-coding-agent.mcp.json`
3. Save
4. Note: this config is stored in GitHub UI, not automatically read from repo files.
5. Optional: If needing more GitHub access, create environment `copilot` and add secret `COPILOT_MCP_GITHUB_PERSONAL_ACCESS_TOKEN`.
